# report 편집기

콘솔 `report create|write <제목>`이 여는 **vim 같은 편집기 층**입니다. 창을 새로 띄우지 않고 콘솔 창 안에서 기록 위에 겹치며, 닫으면 치던 자리로 돌아옵니다. 명령 자체는 `docs/console.md`.

## 화면과 모드

- 메모 전체가 보이고 커서로 아무 곳이나 고칩니다. 아래 상태줄: 제목, 줄 수, 커서 `줄,칸`, 저장 안 한 변경 `[+]`, 메모 상태(`open`·`done x.y.z`·`asked`, 고칠 수 없음), 오른쪽에 모드와 키 안내. 글꼴·색은 콘솔과 같습니다. 줄 번호는 두지 않습니다(사용자 결정).

| 모드 | 들어가기 | 나가기 | 타자 |
| --- | --- | --- | --- |
| 보기(NORMAL) | 처음 열 때, 쓰기에서 Esc | `:q` `:wq` | 글자가 들어가지 않음 |
| 쓰기(INSERT) | 보기에서 `i`(유일한 보기 키, 사용자 결정) | Esc | 커서 자리에 들어감, **Enter는 줄바꿈** |

- 방향키·PageUp/Down·Home/End·클릭·휠은 두 모드 모두 커서를 옮깁니다. Tab은 공백 네 칸. Ctrl+T는 그대로 콘솔을 최소화합니다. 한글 입력(IME)이 됩니다 — 보기 모드도 읽기 전용 상태로 IME를 켜 두어야 합니다.
- 보기 모드에서 쓰지 않는 키는 처리하지 않았다고(false) 돌려줘야 텍스트 이벤트가 살아 `:`가 들어옵니다(`:`는 Shift와 키보드마다 다른 키라 텍스트로만 옵니다).

## 명령줄 (`:`)

| 명령 | 하는 일 |
| --- | --- |
| `:w` `:write` | 저장하고 남음 |
| `:wq` `:x` | 저장하고 터미널로 |
| `:q` `:quit` | 터미널로. 저장 안 한 변경이 있으면 상태줄에서 `[Y/n]` |
| `:copy` | 메모 전체를 클립보드로 |
| `:d` `:delete` | 메모를 지움(묻고, 지운 뒤 터미널로) |

- 없는 명령은 상태줄에 `Not an editor command: :xy`, 명령줄의 Esc는 명령을 지우고 보기로. 편집기의 `[Y/n]`도 글자를 치고 Enter라야 적용됩니다(사용자 규칙).
- 콘솔 창을 닫아도 쓰던 메모는 남아 다시 열면 그 상태로 돌아옵니다(`CmdLog.Report`). 돌아올 곳이 없는 **앱 종료 때만** 저장 안 한 메모를 경고합니다.

## 코드

- `Views/ReportEditor.cs`: 여러 줄 `TextBox` + 상태줄. 공개 면 `Title`·`Lines`·`Changed`·`Insert`·`bool Press(Key, ModifierKeys)`(테스트가 키를 넣는 곳)와 콜백 `Save`·`Delete`·`Leave`. 파일은 직접 건드리지 않고 콜백 끝의 `ICmdHost`가 `ReportBook`으로 씁니다.
- `CmdWindow`: 기록 `TextBox`와 편집기의 두 층, `CmdSession.ReportRequested`로 엽니다.
- 저장: 앱 저장소 `reports/<제목>.txt`(제목은 글자·숫자·공백·`-`·`_`), 상태는 `done.mark`·`written.mark`. 버전이 바뀌어도 지우지 않고, 다시 저장하면 저절로 open이 됩니다.
