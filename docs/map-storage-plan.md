# 맵 저장 구조 · 곡 수정

## 구조

```text
스팀 폴더 (읽기 전용)          구독 중인 창작마당 맵. 앱은 절대 쓰지 않음
앱 저장소 (%LOCALAPPDATA%\AdofaiVisualizer 또는 지정 폴더)
  maps/base/                   게임 기본 맵 (사용자가 넣음)
  maps/custom/                 동기화로 스팀 폴더에서 복사한 .adofai
  maps/edited/<원곡>/<슬롯>/   원본 사본 + edit.json
  maps/removed/                remove로 보관한 수정본 하나
  map-cache/library.json       파싱 결과
  settings.json, songs.json, song-ids.json, song-marks.json, pins.json, redirects.json, reports/
```

## 흐름

| 동작 | 하는 일 |
| --- | --- |
| 동기화 (`sync`) | 스팀 폴더 → custom 복사(증분, `.adofai`만) 후 세 폴더에서 **새로 들어오거나 바뀐 맵만** 파싱(같은 원문을 같은 파서 버전이 읽은 캐시 항목은 그대로, 이전 파서가 읽은 항목은 다시 파싱). 바뀐 것이 없는 폴더는 캐시 파일을 다시 쓰지 않음(사용자 제보: sync가 rebuild만큼 오래 걸림) |
| 곡 그룹 | 목록 필터일 뿐 재파싱하지 않음(사용자 결정) |
| `sync rebuild` | custom을 `custom.new`에 새로 만든 뒤 이름만 바꿔 교체(`.old`를 지움). 실패·취소하면 `.new`만 지우고 기존은 그대로. 구독 해제한 곡은 여기서 사라짐(목적). 세 폴더의 **모든 맵을 다시 파싱** |
| `remove <id>` | 수정본은 `maps/removed/`로 보관(`restore`), 커스텀은 사본 삭제(다시 동기화하면 돌아옴) |
| `delete <id>` | 영구 삭제 |

쓰기 경계: 저장 폴더 밖·맵 폴더·reparse point로 나가지 않는지 쓰기 전마다 검사하고, 서로 다른 곡이 같은 이름이면 비켜 씁니다.

## id

- 내부 식별은 **맵 경로 해시**(곡 리스트 선택·수정본 연결이 유지됨).
- 표시용 8자 id를 `song-ids.json`에 짝지어 둡니다: 첫 자리 종류(`0` 기본 · `1` 커스텀 · `2` 수정본) + 소문자·숫자 7자리(글자 최소 1개), 겹치지 않게 발급. 형식이 맞지 않는 옛 id는 다시 발급합니다.

## 수정본 (사용자 결정)

- **바꿀 수 있는 것은 레인 위치와 동타 병합·분해뿐**입니다. 레인·동타 묶음은 `.adofai`에 없는 개념이라 맵 파일로 표현할 수 없으므로, **원본 `.adofai` 사본 + `edit.json`**(원본 hit 번호 → 타일, 묶음, 원본 해시, 그때의 노트 규칙 설정, 만든·저장 시각)을 한 폴더에 둡니다. 원본 사본은 `sync rebuild`가 custom을 다시 만들어도 수정본이 홀로 서게 하고, 파서를 고쳐도 다시 읽을 수 있게 합니다.
- 불러오면 규칙이 만든 노트 위에 레인·묶음만 덮습니다(`NoteEditLayout.Apply`). 보기 설정(색·두께·이동 시간)은 언제나 현재 값입니다.
- 한 곡당 슬롯 1~9, 목록에는 늘 슬롯 번호(`1*Plum - R`). 저장은 항상 슬롯 선택 창. 수정본을 다시 수정하면 원곡 폴더 아래에 저장합니다.

## 수정 창 조작

- 고르기: 클릭, 드래그 박스, `Ctrl+클릭`, `Shift+클릭`(범위), `Ctrl+A`, Esc/빈 곳 클릭으로 해제. 롱노트는 시작·끝 어느 쪽을 눌러도 둘 다 잡힘. Ctrl+클릭으로 뺄 때 동타는 통째로.
- `w`/`s` 다음·이전 노트(화면이 여유를 두고 따라감), `a`/`d` 한 칸(여러 개면 한쪽이 벽에 닿으면 전체가 멈춤), 숫자 `1`~`8`은 선택 전체를 상대 이동(오른쪽이면 최대 레인이 그 번호, 왼쪽이면 최소 레인이 그 번호, 범위 안이면 그대로).
- 병합은 40ms 안, 사이에 노트가 없는 이웃 레인의 두 노트만. 분해, `Ctrl+F` 뒤집기, 되돌리기·다시 하기, 확대(표시만). 재생·노트 추가·삭제는 없습니다. 오른쪽 도구 패널에 같은 기능이 버튼으로 있습니다.
- 옮길 수 없을 때 모달을 띄우지 않습니다: 벽·화면 밖은 조용히 무시, 레인 충돌·롱노트·병합 조건은 하단 한 줄.
- 노트 위에는 원본 hit 번호(동타는 `44-45`).
