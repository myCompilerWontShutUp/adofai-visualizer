# 시연 가이드

## 최종 점검

- Release 구성 빌드: 경고 0개, 오류 0개.
- 회귀 테스트: 74/74 그룹 통과 (2026-09-13, 실제 맵 읽기 전용 검증과 독립 타이밍 대조 포함). HeHeHe는 동타 10ms 중단 및 0ms 복구를 검증했습니다.
- 확인 범위: 설정/패턴 검증, 경계값, 사이클 전환, Initial Tile, 판정선 사전 배치, Reset/Start 위치 유지, OFF 토글, 시각 설정 적용, 체크포인트 정규화, 자동 체크포인트 토글, 레인 키 입력 효과, 판정선/하단 제거선, 읽기 전용 소스, 캐시 재사용/경로 보호, WPF 렌더링, Windows Raw Input 등록/해제.
- 사용자가 지정한 Workshop 맵 4개를 읽기만 했으며 내용·수정 시각이 유지됨을 확인했습니다. 테스트 fixture와 캡처는 프로젝트 내부에 생성했습니다. 자세한 결과는 [파서 문서](adofai-parser.md)에 있습니다.
- 실제 ADOFAI 타이밍 및 게임 전경에서의 하드웨어 입력 전달은 이번 자동 검증에 포함되지 않습니다.

## 실행할 파일

프로젝트 루트의 **`Launch-Demo.cmd`를 더블클릭**합니다. 빌드나 동기화 없이 아래 Release 실행 파일을 엽니다.

`src/Visualizer.App/bin/Release/net9.0-windows/Visualizer.App.exe`

실행 파일을 직접 더블클릭해도 됩니다. 실행에는 Windows와 .NET 9 Windows Desktop Runtime이 필요하며 현재 개발 환경에는 설치되어 있습니다. 자체 런타임을 포함한 배포 패키지는 아닙니다.

EXE 하나만 다른 폴더로 옮기지 마세요. 같은 폴더의 `Visualizer.App.dll`, `Visualizer.Core.dll`, `Visualizer.Application.dll`, `Visualizer.Infrastructure.dll`, `.deps.json`, `.runtimeconfig.json`이 필요합니다. 현재 개발 빌드는 캐시 저장 경계를 확인하기 위해 상위 프로젝트의 `AGENTS.md`와 `Visualizer.sln`도 사용하므로 프로젝트 안에서 실행하세요.

## 1. 기본 배치와 Reset/Start 시연

기본 시연은 시작 대기 0ms, 배속 100%를 사용합니다. 별도 대기·배속·일시정지와 조사 근거는 [환경 대응 가이드](environment-compatibility.md)에 있습니다. 게임 상태를 자동으로 감지하지 않습니다.

**실제 맵 예제:** **맵 선택**을 펼쳐 **Plum - R 예제**를 누르고 **시작**을 누르면 `.example/main.adofai`에서 계산한 노트를 표시합니다. 체크포인트 목록에서 처음부터 또는 실제 체크포인트 1~6을 선택할 수 있습니다. 오디오는 재생하지 않습니다. 자세한 사용법은 [체크포인트 문서](checkpoints.md)에 있습니다. 설정은 아래쪽 **⚙** 버튼으로 엽니다.

화면 기본 언어는 한국어입니다. 기존 가이드의 Settings는 **setting**, Reset은 **재설정**, Start는 **시작**, Dynamic Timing은 **동적 타일 수**에 해당합니다. `setting → language`에서 English를 선택하면 설정 이름을 영어로 볼 수 있습니다.

1. 실행 후 **규칙 미리보기**를 누릅니다. 외부 맵 없이 합성 타임라인이 로드되고 WAITING이 됩니다.
2. 아래쪽 **⚙**로 setting을 열어 아래 값을 지정하고 **적용**합니다.

   | 설정 | 시연 값 |
   | --- | --- |
   | 일반 → 전역 입력 범위 (ADOFAI가 활성 창일 때만 반응) | OFF — 게임 없이 키 동작을 시연하기 위한 설정 |
   | 키 수 · 패턴 → 최대 타일 수 / 동적 타일 수 | 4 / OFF |
   | 키 수 · 패턴 → 4키 패턴(사용할 타일) / 1키 패턴 · 시작 타일 | 3 4 5 6 (기본 순서로 6 5 4 3) / 5 |
   | 시각화 → 노트 이동 시간 / 판정선 높이 | 700ms / 36px |
   | 노트 표시 → 표시 시간 보정 / 노트 두께 배율 | 0ms / 1.0 |

3. 체크포인트 목록이 **처음부터**인지 확인한 뒤 **재설정** 버튼을 누릅니다. 첫 노트가 5번 타일(J 레인) 판정선에 정지하고, 이후 타일 순서는 `4 → 3 → 6 → 5 …`입니다.
4. **J** 또는 **시작** 버튼을 누릅니다. 이미 보이던 노트가 재배치 없이 이동하고, 판정선을 지나 맨 아래 선에서 사라집니다.
5. 재생 중 **Enter** 또는 **재설정** 버튼을 누르면 다시 정지 배치됩니다. J로 재시작합니다.
6. **F8** 또는 아래쪽 **⏻** 버튼으로 노트 영역을 끄고 켭니다. 다시 켜면 대기 상태이며 자동 재생하지 않습니다.

입력칸이나 콤보박스를 편집하는 중에는 단축키 명령이 실행되지 않습니다. 값 편집 후 Reset 버튼을 클릭하면 포커스 문제 없이 시연할 수 있습니다. 전역 입력 범위(기본 OFF)를 켠 상태에서 게임 밖 시연을 하려면 J/Enter 대신 UI 버튼을 사용하세요.

## 2. Dynamic Timing과 체크포인트 시연

1. Settings에서 **Maximum=8, Dynamic Timing=ON**으로 변경하고 Apply합니다.
2. 목록에서 **체크포인트 2**를 선택합니다. 이 합성 체크포인트는 빠른 구간 가까이에서 시작하며 즉시 정지 배치됩니다.
3. Start를 누릅니다. 합성 자료의 30ms, 10ms 등의 구간에 따라 4K/8K 등의 모드를 사용하며 현재 사이클을 마친 뒤 전환합니다.
4. 다시 Maximum을 **4**로 바꾸면 빠른 구간에서도 8K를 사용하지 않습니다.
5. **처음부터 / 체크포인트 1 / 체크포인트 2**를 선택해 각 기준점에 첫 노트가 준비되는 것을 확인합니다. 전체 미리보기를 재생하면 타임라인 기준으로 체크포인트 표시가 자동 진행합니다.

체크포인트 선택은 재생을 멈추고 선택 구간을 준비합니다. 실제 맵의 체크포인트 파싱도 지원하지만 게임 사망이나 재시작은 자동 감지하지 않습니다.

## 3. 시각 설정 시연

재생 중 Settings에서 **Travel Time**, **Note Thickness**, **Display Offset**만 변경해 Apply합니다. 노트 목록과 진행 시계는 유지하면서 화면에 반영합니다.

- Travel Time을 늘리면 같은 거리를 더 오랜 시간에 이동합니다.
- Thickness=1.5는 기본 시각 두께의 1.5배입니다.
- Offset=+50ms는 표시를 늦추고, -50ms는 앞당깁니다. 원본 hit time이나 체크포인트 시각은 변경하지 않습니다.
- 패턴·최대 키 수·Dynamic Timing·threshold·Initial Tile을 바꾸면 노트를 다시 생성하고 Reset합니다.

설정은 종료하면 기본값으로 돌아갑니다.

## 4. 레인 키와 자동 체크포인트 시연

1. 전역 입력 범위를 OFF로 둔 상태에서 규칙 미리보기를 재생합니다.
2. **D F J K**(기본 4키 화면의 레인 키)를 누르면 해당 레인에 그라데이션이 켜집니다. 노트가 판정선에 올 때 누르면 그 노트가 어두워지고 판정선에 짧은 빛이 납니다. 시각 피드백일 뿐 게임 판정이 아닙니다.
3. setting → 노트 표시에서 **판정선 높이**를 바꾸면 판정선과 맨 아래 선 사이 거리가 바뀝니다. 노트 목록과 재생 시계는 유지됩니다.
4. 체크포인트 줄 오른쪽 **자동** 토글을 끄고 재생하면 체크포인트를 지나도 목록이 바뀌지 않습니다. ◀ ▶ 버튼이나 ↑(다음)/↓(이전)로 직접 이동합니다.

## 5. Map Sync / Load Song 시연 범위

이 절차는 라이브러리를 갱신하고 선택하는 방법입니다. 지원 범위의 실제 맵은 노트를 표시할 수 있으며, 미지원 이벤트가 있는 맵은 이유를 표시합니다.

1. **맵 선택**을 펼쳐 맵 폴더 입력칸에 읽을 Workshop 또는 Custom Level 폴더를 입력합니다.
2. **동기화**를 누르면 `.adofai`를 읽고 라이브러리 캐시를 갱신합니다. 많은 맵이 있으면 시간이 걸릴 수 있으므로 시연에는 작은 맵 폴더가 편합니다.
3. 콤보박스에서 맵을 선택하고 **불러오기**를 누릅니다.
4. 제한된 파서의 지원 범위라면 노트를 준비하고, 지원하지 않는 이벤트가 있으면 **Unsupported**와 이유를 표시합니다. 이전 버전의 Unsupported 캐시는 다시 동기화하세요. 합성 노트를 실제 곡의 타이밍인 것처럼 만들지 않습니다.

Map Sync만 외부 맵 원문을 읽습니다. Load Song과 설정 변경은 캐시를 사용합니다. 캐시 위치는 프로젝트 내부 `.local/app-data/map-cache/library.json`이며 맵 폴더에는 생성·수정·삭제·이동을 하지 않습니다. 실제 맵을 불러온 뒤 다시 노트를 시연하려면 규칙 미리보기를 누르세요.
