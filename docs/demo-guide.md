# 시연 가이드

`Launch-Demo.cmd`를 더블클릭하면 빌드 없이 Release 실행 파일(`src/Visualizer.App/bin/Release/net9.0-windows/Visualizer.App.exe`)을 엽니다. 실행 파일만 다른 폴더로 옮기지 마세요(같은 폴더의 dll·`plugins\linker\`와, 저장소 루트를 찾는 `AGENTS.md`·`Visualizer.sln`이 필요).

## 1. 배치와 재생

1. **규칙 미리보기**(설정판 아래)를 누르면 맵 없이 합성 타임라인이 준비됩니다. 실제 맵은 **예제 (Plum - R)** 또는 동기화한 곡을 불러옵니다.
2. 게임 없이 키로 시연하려면 설정의 **전역 입력 범위**를 끕니다.
3. **Enter**(재설정)로 첫 노트를 판정선에 세우고 **J**로 시작합니다. 노트는 재배치 없이 내려와 판정선을 지나 제거선에서 사라집니다. **F8**로 켜고 끕니다(다시 켜면 대기, 자동 재생 없음).
4. 레인 키(기본 4레인 화면 `D F J K`)를 누르면 레인이 빛나고, 판정선에 온 노트를 누르면 어두워집니다(시각 피드백일 뿐).
5. **Esc**로 일시정지하면 다음 노트가 판정선에 맞춰지고, 레인 키로 재개합니다.

## 2. 규칙 바꿔 보기

- 설정에서 최대 타일 수·Dynamic·경계값·패턴을 바꾸고 적용하면 노트를 다시 준비합니다. 설정판의 **미리보기**는 적용하지 않은 값으로 바로 재생합니다.
- 이동 시간·두께·표시 보정·색만 바꾸면 노트와 재생 시계가 유지됩니다.
- 체크포인트 목록·◀ ▶·구간 칸으로 시작 위치를 바꿉니다. 두 번째 이후 체크포인트·구간은 첫 노트 레인 키로 시작합니다.

## 3. 곡 수정과 콘솔

- **Ctrl+E**로 불러온 곡의 수정 창(레인·동타)을 엽니다. 오른쪽 도구 패널에 모든 조작이 버튼으로 있습니다.
- **Ctrl+T**로 콘솔을 엽니다. `cmd`로 명령 목록, `note 1..20`으로 노트, `go 100`으로 타일 100부터.

테스트가 렌더링한 화면은 `.local/test-artifacts/`의 `main-window.png` 등입니다(실행 영상이 아님).
