- 성능 규칙: 레인 키·시작 키처럼 자주 눌리는 입력 경로에서 전체 바인딩 갱신(`NotifyAll`)이나 프로세스 열거를 하지 않습니다. 무시된 명령은 알림을 보내지 않고, 체크포인트 목록은 타임라인·언어별로 캐시하며, `NoteField`는 재생·효과 중에만 매 프레임 다시 그립니다. 노트처럼 프레임마다 여러 개 그리는 도형에는 상대 좌표 그라데이션 브러시를 쓰지 않습니다(측정상 합성이 약 120fps에서 80fps로 느려짐).
