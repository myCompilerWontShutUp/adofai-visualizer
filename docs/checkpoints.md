# 체크포인트와 구간 시작

## 사용

- 곡을 불러오면 메인 화면의 체크포인트 목록에서 **처음부터** 또는 **체크포인트 n**을 고릅니다(표시는 `체크포인트 1 · 타일 64 → 64`처럼 원본 타일과 재시작 타일). 고르면 즉시 정지 배치하고, 시작 키로 재생합니다. 콘솔은 `checkpoint`(번호·`first`·`next`·`previous`·`last`·`list`).
- 이전/다음 체크포인트 키(기본 `-`/`+`)와 ◀ ▶는 목록 양 끝에서 순환합니다. 체크포인트가 1개 이하이면 ◀ ▶는 비활성입니다.
- **자동 체크포인트**: 재생 중 지나간 체크포인트로 선택이 넘어갑니다. 그 타일의 노트를 누른 순간, 누르지 않으면 그 노트의 입력 인정 범위가 끝날 때 적용합니다(표시 시각 기준이라 동타·배속·시작 대기·표시 보정을 반영, 일시정지 중에는 멈춤). 게임은 배속이나 연습 구간에서 체크포인트를 쓰지 않으므로 **배속≠100%이거나 구간에서 시작하면** 자동 진행이 꺼지고 토글이 잠깁니다. 불러오기 자동 체크포인트(기본 켜짐)는 곡을 불러올 때 다시 켭니다.
- 게임 사망·체크포인트 선택은 감지하지 않습니다(게임 링크로 따라갈 때 제외). 재설정은 현재 선택된 구간을 다시 준비합니다.

## 근거와 지원 경계

설치된 게임의 `Assembly-CSharp.dll`(SHA-256 `0D1524DABF0F8C67AA58BA1992D6ED858522B9094490EBBB00E5E8AEFF7F40CD`)을 ReflectionOnly로 읽어 확인했습니다(`.local/inspect-checkpoint.ps1`).

- `ffxCheckpoint.get_runOnHit`: 타일 타격 때 실행되는 이벤트.
- `ffxCheckpoint.Decode`: tileOffset 기본 0, `floor + tileOffset`을 0~`listFloors.Count - 2`로 제한.
- `ffxCheckpoint.StartEffect`: `floor.seqID + tileOffset`을 재시작 위치로 저장하며 기존 위치보다 클 때만 갱신.
- `scnGame.FinishCustomLevelLoading`: 저장된 타일을 현재 위치로 두므로, 재시작 타일 **이후** 첫 hit부터 준비합니다.
- 중간 회전 타일 위의 체크포인트 이벤트는 재시작 타일이 일반 타일이면 허용합니다(`scrPlanet.MoveToNextFloor`·`scrPlayer.Hit`이 중간 회전 타일도 현재 타일로 다룸, 저장 위치는 이벤트 타일과 무관).

`TimelineCheckpoint`는 활성화 시각·원본 floor·재시작 floor·재시작 후 첫 hit index를 따로 둡니다(양수 offset으로 표시가 늦게 바뀌거나 음수 offset으로 이전 체크포인트로 돌아가는 것을 막음). Pause로 늘어난 시간은 이후 활성화 시각에도 반영됩니다.

지원하지 않음: 시작/종료 타일의 체크포인트, 중간 회전 타일로의 재시작, 조건부·angleOffset 체크포인트, 체크포인트를 반복하는 RepeatEvents, FreeRoam 타일로의 재시작, 롱노트 도중 재시작.

## 구간 시작 (게임 연습 모드와 같은 타일 번호)

노트 영역 위 **구간** 칸(또는 콘솔 `go <타일>`)에 타일 번호를 넣으면 그 타일부터 정지 배치합니다. 칸을 비우거나 체크포인트를 고르면 해제됩니다. 재설정·켜기·규칙 변경 뒤에도 같은 타일에서 다시 준비하고, 자동 진행은 이 위치보다 앞의 마지막 체크포인트부터 이어집니다. 콘솔 `pin`으로 꽂은 타일은 `go`의 Tab 후보입니다.

- **배치와 시작 키**: 구간과 두 번째 이후 체크포인트는 곡 처음부터 만든 배치를 **잘라 씁니다**. 그래서 같은 노트는 처음부터 재생할 때와 같은 레인이고, 시작 키는 **첫 노트 레인의 키**(동타면 두 레인 키)입니다. 처음부터만 Initial Tile·시작 키입니다. 곡 앞부분에 배치할 수 없는 동타가 있으면 뒤에서 시작해도 준비가 중단됩니다.
- **근거**: `scrController.SetPracticeMode`와 `PracticeTimeline.Init`/`SetPositions`가 연습 시작 타일을 보정 없이 `GCS.checkpointNum`에 넣으므로, 체크포인트와 같은 규칙으로 **그 타일 이후 첫 hit**부터 준비합니다. 중간 회전 타일과 마지막 타일 이후는 거부하고, 연습 구간 끝(`practiceLength`)과 게임 배속은 적용하지 않습니다.
- 타일 번호는 파서가 hit마다 캐시에 저장합니다(합성 미리보기에는 없어 구간을 쓸 수 없음).
